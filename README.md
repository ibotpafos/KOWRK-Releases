# KOWRK для macOS

Подписанные сборки для Apple Silicon и macOS 15+. Скачайте архив со страницы [Releases](https://github.com/ibotpafos/KOWRK-Releases/releases/latest).

Для входа в приложение нужен аккаунт GD.MUZ с приглашением в команду. Сборка подписана самоподписанным сертификатом KOWRK. При первом открытии macOS может потребовать подтверждение.
